# Universal QR Code Scanner 🔍

A modern, feature-rich PWA for scanning QR codes, barcodes, and product codes with built-in rewards system.

## Features ✨

- **Real-Time QR & Barcode Scanning** - Powered by ZXing library
- **Rewards System** - Earn coins with every scan
- **Google Authentication** - Secure sign-in with Google
- **Offline Support** - PWA with service worker caching
- **Responsive Design** - Mobile-first dark theme
- **Coupon Redemption** - Apply promo codes for bonus coins
- **Scan History** - View recent scans
- **Android Install** - Add to home screen as standalone app
